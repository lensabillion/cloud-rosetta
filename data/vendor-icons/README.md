# Official service artwork

Retrieved 15 September 2026 from the providers’ public architecture libraries. The 20 SVGs
are original package members, unchanged; `manifest.json` records their original paths.
The guide embeds them in its exported SVGs so viewing does not require an external icon host.
Provider artwork retains its original colors and proportions. Surrounding diagram styling
uses `data/design.yml`; the documented artwork exception does not apply to authored UI colors.
These assets remain subject to their owners’ rights and usage terms, not the repository license.

| Provider | Official guidance | Download used |
| --- | --- | --- |
| AWS | [Architecture icons](https://aws.amazon.com/architecture/icons/) | [July 2026 package](https://d1.awsstatic.com/onedam/marketing-channels/website/public/shared/architecture-icon-release/Icon-package_07312026.5846e92413caa21490223536cc97f1269e44fa92.zip) |
| Microsoft Azure | [Architecture icons and permitted uses](https://learn.microsoft.com/en-us/azure/architecture/icons/) | [V24 package](https://arch-center.azureedge.net/icons/Azure_Public_Service_Icons_V24.zip) |
| Google Cloud | [Icon library](https://cloud.google.com/icons), [product icon guide](https://services.google.com/fh/files/misc/google-cloud-product-icons.pdf) | [Core products](https://services.google.com/fh/files/misc/core-products-icons.zip), [categories](https://services.google.com/fh/files/misc/category-icons.zip) |

Google’s current system uses distinct core-product icons and shared category icons for other
products. Cloud Load Balancing and Cloud Armor use Networking; Firestore uses Databases.
Azure Blob Storage is represented by its Storage Account resource icon. AWS ALB uses the
Elastic Load Balancing service icon. Product labels always identify the actual service.

Do not crop, rotate, recolor, distort or imply vendor endorsement. When updating, review the
current provider guidance and retain the original artwork and a traceable package member.
