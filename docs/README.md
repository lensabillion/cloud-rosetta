# Chapter Index

Cloud Rosetta in reading order. Start at the top if you are new; jump to the decoder if you
already know one cloud and are learning a second.

## Read in Order

| | Chapter | What it does |
| --- | --- | --- |
| 00 | [The Landscape](00-landscape.md) | What the three providers are, market position, who uses them, and the vocabulary shared by all three. Five minutes, no prior knowledge |
| 01 | [Mental Models](01-mental-models.md) | Why the clouds are shaped differently. Account against subscription against project, and what is global, regional or zonal |
| 02 | [Identity and Access](02-identity.md) | Who may do what. The area candidates report failing most |
| 03 | [Networking](03-networking.md) | Virtual networks, firewalls, private access, load balancers |
| 05 | [Databases](05-databases.md) | Read scaling against surviving failure, and why the two get confused |
